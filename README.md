
# Irrigation Scheduler

Irrigation Scheduler is a lightweight Java application for planning automatic irrigation based on schedules and weather conditions.

## Features

- Irrigation schedules
- Multiple watering zones
- Weather forecast support
- Automatic watering skip
- Water consumption estimation
- Daily reports
- Statistics
- Console interface

## Project Structure

```
src/
 ├── config
 ├── models
 ├── services
 ├── utils
 └── resources
```

## Build

```bash
mvn clean package
```

## Run

```bash
mvn exec:java
```
